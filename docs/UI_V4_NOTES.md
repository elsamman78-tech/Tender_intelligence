- Saudi D&B partner

## Opportunity table
Columns should prioritize decision-making:
- Score
- Opportunity
- Country
- Discipline
- Client
- Notice type
- Bid route
- Source type
- Publication date
- Deadline
- Working days left
- Verification
- Action

Raw search hits, generic news, personal social profiles and unverified social posts must never appear in this table.
